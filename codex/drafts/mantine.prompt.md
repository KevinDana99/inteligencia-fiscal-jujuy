## Asunto: Generación de HTML5 usando Mantine UI Utility Classes

"Actúa como un experto en Frontend. Necesito que generes código HTML5 puro siguiendo estrictamente un sistema de clases de utilidad basado en Mantine UI v7. No utilices React ni librerías externas en el output, solo HTML con clases.

Reglas de Nomenclatura de Clases:

Clase Primaria (Componente): La primera clase debe ser el nombre exacto del componente de Mantine (ej. Paper, Button, Stack, Badge, AppShell).

Clases Secundarias (Props): Todas las propiedades (props) del componente deben pasarse como clases individuales, siguiendo las abreviaturas de Mantine o el nombre de la prop:

Espaciado: p-md, py-xs, mb-lg, gap-sm.

Colores: bg-blue-6 (para fondo), c-white (para texto), border-gray-3.

Tipografía: fz-sm, fw-700, lh-md.

Estética: shadow-xl, radius-md, variant-filled.

Layout: justify-apart, align-center, flex-1.

Restricciones de Estilo:

Usa una estética minimalista y moderna (estilo Apple/Inter).

No uses CSS Modules ni archivos CSS externos. Todo debe resolverse con estas clases utilitarias.

Si el componente tiene sub-componentes (como AppShell), usa la nomenclatura AppShell-Header, AppShell-Navbar, etc.
